# ⚡ Aegis AI — Terminal Cybersecurity & Coding Assistant

A fast, minimal, powerful AI assistant for your terminal.  
Powered by **Groq API** with model `openai/gpt-oss-120b`.

---

## 🚀 Quick Start

### 1. Install Dependencies

```bash
pip install groq rich
```

### 2. Set Your Groq API Key

**Linux / macOS:**
```bash
export GROQ_API_KEY="your_groq_api_key_here"
```

**Windows (CMD):**
```cmd
set GROQ_API_KEY=your_groq_api_key_here
```

**Windows (PowerShell):**
```powershell
$env:GROQ_API_KEY="your_groq_api_key_here"
```

> Get your free API key at: https://console.groq.com

### 3. Run Aegis AI

```bash
python aegis.py
```

---

## 💬 Commands

| Command | Action |
|---------|--------|
| Type anything | Ask Aegis AI a question |
| `clear` | Reset chat history |
| `exit` or `quit` | Exit the assistant |
